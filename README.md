# Sembilan Puluh - Halaman Maintenance / Work In Progress

Paket halaman web statis berbasis **HTML5** dan **Tailwind CSS** untuk tampilan *Work In Progress / Under Maintenance*.

## Struktur File
- `index.html` — Halaman utama dengan logo terpusat, tipografi modern, latar grid arsitektural halus, dan animasi transisi.
- `assets/logo-sembilan-puluh.png` — File logo resmi perusahaan.

## Cara Menggunakan
1. Ekstrak file `.zip` ini.
2. Buka `index.html` langsung di browser untuk melihat tampilan, atau unggah seluruh isi folder ke hosting/server (cPanel, Netlify, Vercel, Cloudflare Pages, dll).
3. Sesuaikan tautan email (`halo@sembilanpuluh.id`) dan nomor WhatsApp (`https://wa.me/6280000000000`) pada bagian `<footer>` di `index.html` sesuai kontak resmi perusahaan.
